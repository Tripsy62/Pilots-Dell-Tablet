# Drivers-Dell-Tablet
⚠️ONLY WORK ON WINDOWS⚠️
Here are the drivers for Dell Tablet Venue. 
Maybe it works on others tablets
You can modify some Windows ISO to add the drivers (I use NTLite) 
to the iso to make the installation easier.
If you already have windows, open a terminal as 
administrator, move into the drivers file
and type this command :
  "pnputil /add-driver *.inf /subdirs /install"
And after everything is installed, you will simply need to restart.
